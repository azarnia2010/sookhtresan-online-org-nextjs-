# سامانه سازمانی سوخت‌رسان — Next.js + Supabase

این نسخه، سامانه را به یک برنامه آنلاین چندکاربره تبدیل می‌کند. سایت Next.js روی Vercel اجرا می‌شود و اطلاعات در PostgreSQL میزبانی‌شده در Supabase نگهداری می‌شوند.

## ساختار حساب‌ها

- مدیر کل: یک حساب
- مدیر عملیات: یک حساب
- رانندگان سوخت‌رسان: شش حساب جداگانه

همه از یک آدرس وارد می‌شوند؛ نقش هر حساب تعیین می‌کند کدام پنل نمایش داده شود. دو مدیر گزارش همه رانندگان سازمان را مشاهده و بررسی می‌کنند. هر راننده فقط گزارش‌های خود را می‌بیند.

## فناوری‌ها

- Next.js App Router، React و TypeScript
- Supabase PostgreSQL برای دیتابیس مرکزی
- Supabase Auth برای ورود کاربران
- Supabase Realtime برای به‌روزرسانی زنده داشبورد مدیر
- Row Level Security (RLS) برای محدود کردن دسترسی داده‌ها

## امکانات این نسخه

- ثبت آنلاین تحویل سوخت از پنل راننده
- ثبت پلاک، مشتری، نوع سوخت، مقصد، مقدار لیتر و اطلاعات مالی
- محاسبه مبلغ از روی قیمت واحد یا ثبت مبلغ دستی
- داشبورد روزانه مدیر با جمع گزارش‌ها، لیتر و مبلغ
- گزارش تفکیکی عملکرد شش راننده
- تأیید یا برگشت گزارش برای اصلاح توسط مدیر و امکان اصلاح و ارسال دوباره گزارش ردشده توسط راننده
- فعال و غیرفعال‌سازی حساب راننده
- ثبت ردپای تغییرات گزارش‌ها (Audit Log)
- نشست کاربری کوکی‌محور و عدم Cache کردن صفحه‌های احراز هویت‌شده

## راه‌اندازی سریع

مراحل کامل و تصویری/گام‌به‌گام در فایل `DEPLOY-ORGANIZATIONAL.fa.md` نوشته شده است. خلاصه مراحل:

1. Supabase را از Vercel Marketplace به پروژه متصل کن.
2. متغیرهای `NEXT_PUBLIC_SUPABASE_URL` و `NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY` را در Vercel بررسی کن.
3. محتوای `supabase/schema.sql` را در Supabase SQL Editor اجرا کن.
4. `provision-users.example.json` را به `provision-users.json` کپی کن؛ ایمیل‌های واقعی و رمزهای قوی ۸ حساب را جایگزین کن.
5. `.env.provision.example` را به `.env.provision` کپی کن و کلید محرمانه Supabase را فقط در این فایل محلی قرار بده.
6. با Node.js 22 در پوشه پروژه اجرا کن:

```bash
npm install
npm run db:provision
```

7. فایل‌ها را به GitHub بفرست تا Vercel Deploy کند.

## اجرای محلی

ابتدا متغیرهای عمومی Supabase را در `.env.local` تنظیم کن (از روی `.env.example` کپی کن):

```bash
npm install
npm run dev
```

سپس `http://localhost:3000` را باز کن.

## فرمان‌های بررسی

```bash
npm run typecheck
npm run test:smoke
npm run build
```

## فایل‌های مهم

- `supabase/schema.sql`: جداول، RLS، توابع مدیریتی، Audit و Realtime
- `scripts/provision-users.mjs`: ساخت دو مدیر و شش راننده با Supabase Admin API
- `provision-users.example.json`: الگوی امن تعریف ۸ کاربر
- `.env.example`: متغیرهای عمومی برنامه
- `.env.provision.example`: الگوی محلی و محرمانه راه‌اندازی حساب‌ها
- `DEPLOY-ORGANIZATIONAL.fa.md`: راهنمای کامل راه‌اندازی و انتشار

## محدوده فعلی

این نسخه مسیر ورود، ثبت و بررسی گزارش تحویل سوخت را آنلاین می‌کند. موجودی مخزن، GPS زنده، مدیریت خودروها، اعلان Push، بازیابی رمز ایمیلی، خروجی Excel/PDF و رابط ساخت کاربر جدید هنوز در این نسخه پیاده‌سازی نشده‌اند. برای بهره‌برداری سازمانی، اطلاعات شرکت و کاربران و روندهای مالی باید با داده‌های واقعی و مسئولان سازمان آزمایش و تأیید شوند.
